# Multi-Service Website with Admin Panel

A comprehensive Next.js application providing real estate, solar energy, and digital marketing services with a full-featured admin panel for content management.

## Features

### Frontend
- 🏠 **Real Estate Listings** - Browse and search properties
- ☀️ **Solar Solutions** - Solar energy consultation and quotes  
- 📈 **Digital Marketing** - Marketing services and lead generation
- 🎨 **Responsive Design** - Mobile-first, modern UI with Tailwind CSS
- 🌙 **Dark/Light Mode** - Theme switching support

### Admin Panel
- 📊 **Dashboard** - Overview of all site metrics and activities
- 📝 **Content Management** - Edit page content, sections, and metadata
- 🏘️ **Property Management** - Add, edit, and manage property listings
- 📞 **Lead Management** - Track solar and marketing leads
- 👥 **User Management** - Manage user accounts and roles
- ⚙️ **Site Settings** - Configure site-wide settings and branding

### Database Integration
- 🔥 **Firebase/Firestore** - Real-time database for all content
- 🔐 **Authentication** - Secure admin access
- 💾 **Data Persistence** - All content changes saved automatically

## Getting Started

1. **Install dependencies**: `npm install`
2. **Configure Firebase**: Update `.env.local` with your Firebase config
3. **Run development server**: `npm run dev`
4. **Visit**: http://localhost:9002
5. **Admin Panel**: http://localhost:9002/admin

## Tech Stack
- Next.js 15, TypeScript, Tailwind CSS, Firebase, Radix UI
