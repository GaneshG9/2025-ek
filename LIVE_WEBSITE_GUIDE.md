## ⚡ Quick Setup (5 Minutes to Go Live!)

### Step 1: Create GitHub Repository
1. **Go to GitHub**: https://github.com/new
2. **Repository name**: `eka-2025`
3. **Visibility**: ✅ Public (required for free GitHub Pages)
4. **Don't initialize** with README (we already have files)
5. **Click**: "Create repository"

### Step 2: Push Your Code
```bash
# Add GitHub as remote (replace YOUR_USERNAME with your GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/eka-2025.git

# Rename branch to main for GitHub Pages
git branch -M main

# Push all your code to GitHub
git push -u origin main
```

### Step 3: Enable GitHub Pages
1. **Go to your repository**: `https://github.com/YOUR_USERNAME/eka-2025`
2. **Click "Settings" tab** (top navigation)
3. **Scroll down to "Pages"** (left sidebar)
4. **Configure deployment**:
   - **Source**: Deploy from a branch
   - **Branch**: main
   - **Folder**: / (root)
5. **Click "Save"**

### Step 4: Wait for Deployment (2-3 minutes)
- GitHub will show: "Your site is ready to be published at `https://YOUR_USERNAME.github.io/eka-2025/`"
- **First deployment takes 2-3 minutes**
- You'll see a green checkmark when ready ✅
